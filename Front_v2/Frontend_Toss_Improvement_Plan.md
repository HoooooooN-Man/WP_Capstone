## 1. 전역 셸(Global Shell) 재설계 — 최우선

현재는 모든 페이지가 `AppHeader + BottomNav + 래퍼 div`를 복붙하고, 다크모드 state도 페이지마다 따로 들고 있음. 토스처럼 **고정 셸 + 가변 본문** 구조로 바꾼다.

### 1.1 `<AppLayout>` 도입
```
<AppLayout>
  ├─ <AppHeader>          (상단 고정, 64px)
  ├─ <SubNav>             (영역별 서브탭, 44px, 해당 시에만)
  ├─ <main> {children}    (가변, 좌우 레일과 함께 그리드)
  ├─ <ContextRail>        (데스크탑 우측 고정, 320px) ← 신규
  ├─ <MarketTickerBar>    (하단 고정, 36px) ← 신규
  └─ <BottomNav>          (모바일 전용 하단, 56px)
```
- 14개 페이지의 셸 중복 제거. 페이지는 본문만 책임.
- `paddingTop:'72px'` 같은 매직넘버 셸에서 일원화.

### 1.2 데스크탑 본문 그리드
```
┌──────────────────────────────────────────────┐
│ AppHeader                                     │
├──────────────────────────────────────────────┤
│ SubNav (영역 진입 시)                          │
├───────────────────────────────┬──────────────┤
│                               │              │
│   main (max 1024px)           │ ContextRail  │
│                               │  (320px)     │
│                               │              │
├───────────────────────────────┴──────────────┤
│ MarketTickerBar (KOSPI · KOSDAQ · 환율 · 코스피200)│
└──────────────────────────────────────────────┘
```
- `ContextRail`: 상단=오늘의 시장 점수(게이지), 중단=관심종목 미니리스트, 하단=최근 본 종목. 1280px 미만에서는 숨김.
- `MarketTickerBar`: `useMarketRegime` 데이터 + 지수. 항상 노출돼 "살아있는 화면" 느낌.

### 1.3 전역 다크모드 (버그 수정 겸)
- `next-themes`(이미 설치됨) `ThemeProvider`를 `main.tsx`에 추가.
- 페이지별 `useState(isDark)` 14곳 전부 제거 → 헤더 토글만 `useTheme()`.
- **현재는 페이지 이동 시 다크모드가 풀리는 실버그** — 이걸로 해소.

## 2. 페이지별 개선 — 사용 흐름 + UI 배치

### 2.1 종목 상세 (`StockDetailPage`) — 가장 큰 개선폭

**현재 문제**: 7탭 세로 스택, 탭마다 빈 카드 하나, diagnosis 탭은 삼성전자 텍스트 하드코딩, 화면 절반이 여백.

**토스식 재배치 (데스크탑)** — 종목홈을 카드 대시보드로:
```
┌─ 종목 헤더 (로고·이름·티커·섹터 | 현재가·등락 | 신호칩·관심추가) ─┐
│  └ 인라인 미니정보: 52주범위 · 거래량 · 시총 · PER · 외국인비중   │
├──────────────────┬──────────────────┬───────────────────────┤
│ 가격 차트 카드    │ 스마트스코어 카드  │ 적정주가 밴드 카드      │
│ (기간탭 1D/1W/1M  │ (점수 게이지 +    │ (5색대 + 현재가 마커)  │
│  /3M/1Y, 캔들/라인)│  5요인 레이더)    │                        │
├──────────────────┴──────────┬───────┴───────────────────────┤
│ AI 진단 리포트 (강점/주의)    │ 누적수익·아웃컴 카드           │
├──────────────────────────────┼───────────────────────────────┤
│ 관련 뉴스 (썸네일 3건 + 더보기)│ 재무 요약 (매출/영익 미니바)   │
├──────────────────────────────┴───────────────────────────────┤
│ 경쟁사 비교 표                                                 │
└────────────────────────────────────────────────────────────────┘
```
- **탭은 유지하되 의미 재정의**: `종목홈`(위 대시보드 요약) / `차트·진단` / `밸류·재무` / `뉴스·공시` / `경쟁사`. 7탭 → 5탭으로 축소.
- 각 탭은 "카드 1개"가 아니라 관련 카드 묶음.
- **diagnosis 하드코딩 텍스트 즉시 제거** → radar API의 그룹 점수로 강·약점 자동 생성, 데이터 없으면 EmptyState.
- 모바일: 카드 그리드 → 1컬럼 세로 스택(자동), 탭은 가로 스크롤 유지.
- `window.location.href`(경쟁사 표) → `navigate()` 로 교체.
- 죽은 코드 `{false && ...}` 2블록 삭제.

**사용 흐름**: 추천 리스트 행 클릭 → 종목홈(요약 한눈에) → 궁금한 영역 탭 클릭 → 관심추가는 헤더에서 항상 가능 → 우측 ContextRail의 "최근 본 종목"에 자동 누적.

### 2.2 추천 (`RecommendPage`) — 메인

**현재**: Top-3 히어로 + 와이드 리스트(행 100px). 기본 골격은 좋음. 토스 피드(`06_feed`)의 "큐레이션 카드" 느낌 일부 차용.

- 상단 컨트롤 바 + 신호필터 칩 + 정렬 토글이 **3줄로 분산** → 한 줄 `<FilterBar>` 로 통합 (성향·다양화 드롭다운 | 신호칩 | 정렬). 모바일은 "필터" 버튼 → 바텀시트(`vaul` 설치돼 있음).
- Top-3 히어로: 토스 피드처럼 "왜 추천했는지" 한 줄(headline) 강조 + 점수 변화 화살표.
- 와이드 리스트 행 100px는 토스 스크리너 대비 저밀도 → 64~72px로 압축, headline은 1줄 말줄임.
- "더보기" 버튼 → 무한 스크롤 또는 페이지네이션(현재 topK+20 방식은 매번 전체 재요청).
- 우측 ContextRail에 "오늘의 시장 점수" 게이지가 들어가므로, 본문 상단의 시장점수 표시는 제거 가능 → 컨트롤 바 슬림해짐.

### 2.3 검색 (`SearchPage`)

- 이모지 제거(🔥📈) — 디자인 시스템상 아이콘은 lucide로 통일(`Flame`, `TrendingUp`).
- 검색 입력에 **자동완성 드롭다운**(현재는 결과가 본문 카드로 떨어짐) → 토스처럼 입력 즉시 오버레이 리스트.
- 결과 행 클릭 외에 **키보드 ↑↓ + Enter** 지원.
- `cmdk`(설치됨)로 커맨드팔레트형 검색 고려 — `Ctrl+K` 전역 단축키.

### 2.4 발굴 영역 (스크리너·섹터·스마트스코어·뉴스) — 좌측 레일 도입

토스 `05_screener`의 좌측 카테고리 레일을 차용. 현재는 상단 서브탭만 있어 항목이 늘면 답답.

```
┌─────────┬──────────────────────────────────┐
│ 좌측레일 │  본문                             │
│ ─────── │                                  │
│ 스마트  │  [선택된 도구의 결과 표/차트]      │
│  스코어 │                                  │
│ 섹터분석│                                  │
│ 스크리너│                                  │
│ 뉴스    │                                  │
│ 종목비교│                                  │
└─────────┴──────────────────────────────────┘
```
- **스크리너**: 토스식 고밀도 정렬표. 컬럼 = 순위·종목(로고)·현재가·등락률·거래대금·시총·점수·스파크라인. 헤더 클릭 정렬. 행 높이 48~56px.
- **뉴스**: 썸네일 + 제목 + 요약 스니펫 2줄 + 출처·시간. 상단 필터칩(전체/종목/섹터). 현재 텍스트-only → `ImageWithFallback`(이미 있음) 활용.
- **섹터분석**: 토스 `04_analytics`의 도넛+범례 패턴 — 섹터별 점수 분포 도넛 + 섹터 클릭 시 종목 리스트.
- **스마트스코어**: 점수대별 분포 + 티어별 종목.
- 모바일: 좌측 레일 → 상단 가로 스크롤 칩.

### 2.5 관심 / 마이 / 포트폴리오

- **관심종목**: 토스 우측 사이드바 미니리스트의 풀버전. 와이드 리스트 재사용 + 정렬/그룹.
- **마이포트폴리오**: 토스 `01`의 "매매·투자 정보" 카드처럼 — 보유종목 손익 카드 + 리밸런싱 진단. ContextRail에도 요약 노출.
- **로그인/회원가입**: 2단 레이아웃 양호. 다크모드 토글 버튼은 전역 헤더로 이동(페이지에서 제거).

## 3. 디자인 시스템 정리 (개선의 토대)

토스 화면이 일관돼 보이는 이유는 **토큰을 지킨다**는 것. 우리는 토큰(`theme.css`)을 만들어놓고 인라인 스타일로 우회 중 → 이걸 정리해야 위 개선이 지속 가능.

1. **타이포 스케일 고정**: 현재 13/14/16/18/20/22/28/36/40px 난립 → `text-xs~text-3xl` 6단계로 정리, Tailwind 유틸로.
2. **인라인 `style={{}}` → 토큰 클래스**: 점진 이전. 신규/수정 컴포넌트부터 강제.
3. **호버는 CSS `:hover`로**: `onMouseEnter/Leave` JS 토글 전부 제거(키보드·터치 대응).
4. **`:focus-visible` 스타일 추가**: 접근성. 현재 전무.
5. **스켈레톤 일원화**: `LoadingSkeleton`·`Skeleton` + 페이지별 자체 펄스 → 하나로.
6. **차트**: 손그림 SVG → `recharts`(설치됨)로. 반응형 컨테이너로 모바일 가로스크롤 제거.
7. **공통 컴포넌트 추출**: `<Card>`, `<StatTile>`, `<SectionHeader>`, `<DataTable>`, `<FilterBar>` — 페이지 코드가 절반으로 줄어듦.
8. **에러/로딩/빈상태 3종 일관 처리**: 현재 일부 탭은 에러도 "불러오는 중..."으로 표시되는 버그.

## 5. 핵심 사용 흐름 (To-Be)

```
진입
 └ 추천(메인): 오늘의 Top-3 + 와이드 리스트 + 우측 시장점수
    │  └ 필터바로 성향·신호·정렬 즉시 조정
    ▼ 행 클릭
 종목상세(종목홈): 차트·스코어·밸류·진단 카드 한눈에
    │  └ 탭으로 심화(차트·진단 / 밸류·재무 / 뉴스 / 경쟁사)
    │  └ 헤더에서 관심추가 → ContextRail "관심종목"에 즉시 반영
    │  └ 본 종목은 ContextRail "최근 본 종목"에 누적
    ▼
 발굴: 좌측 레일에서 도구 선택(스크리너/섹터/뉴스/비교)
    └ 스크리너 표에서 종목 발견 → 종목상세로
 검색: Ctrl+K 어디서나 → 자동완성 → 종목상세
 관심/마이: ContextRail에서 바로, 또는 풀페이지로
하단 MarketTickerBar: 어느 화면에서나 시장 흐름 인지
```

토스의 본질은 **"화면을 떠나지 않고 맥락을 유지한다"** — 우측 레일·하단 시세 띠·종목상세 내 탭이 그 장치. 우리 앱도 이 3가지를 넣으면 페이지 단위 이동감이 사라지고 "하나의 도구"로 느껴진다.
